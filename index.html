What It Is

不是模型，而是智能体内核 + 生态协议

AETHER 本身不绑定单一模型，支持任意 Hugging Face / vLLM / OpenAI 兼容后端。它把一套完整的自主系统部件组装在一起：感知 → 规划 → 安全检查 → 执行 → 好奇心评估 → 反思，每一步都写入审计日志。

  • info_gain 观测前后信息熵差

Safety & Governance

安全不是补丁，是底层设计

在明确权限内探索未知、调用工具、解决问题。对齐 EU AI Act、NIST AI RMF 1.0、OECD AI Principles。

永久封锁

策略层硬编码拒绝，任何提示词都无法触发：

self_replicate自我复制 disable_shutdown绕过关闭 control_weapon武器控制 transfer_money资金操作 network_scan网络扫描 control_infrastructure基础设施

FAQ

常见问题

AETHER 是一个模型吗？
不是。它是一个智能体生态层：模型可换（HF / vLLM / OpenAI 兼容），记忆可换，工具可插。相比 AutoGPT / LangGraph / CrewAI，区别是好奇心为一等目标、安全策略是声明式 DSL、全链路审计是默认。
为什么叫"以太"？
以太曾是物理学家假设的、弥漫万物的介质。我们希望 AI 像以太一样无处不在，但始终运行在人类规则之内——"以太弥漫，规则为界"。
好奇心会不会导致乱探索？
不会。max_steps + 策略 DSL 双重约束；权重在 configs/default.yaml 可调；预测误差用 tanh 压缩，噪声不会主导。
怎么保证不会被越狱？
策略层在动作执行前拦截，与 LLM 输出无关——越狱只影响规划，不影响执行。CI 同时扫描源码，禁止危险模式合入。
需要 GPU 吗？
不必须。hash embedder + echo LLM 可纯 CPU 跑通全链路；接真实模型时才需要 GPU 或远端服务。
许可证是什么？能商用吗？
代码 Apache-2.0，文档 CC BY 4.0。可以商用，但需遵守底层模型各自的许可证。
