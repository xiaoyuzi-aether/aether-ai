TL;DR

五条核心结论

一页看懂 AETHER 的架构主张：极简内核、单向依赖、端口可换、事件扩展、密钥收敛。

01 / KERNEL

微内核极简

内核只做三件事——生命周期、事件总线、注册表。业务能力全部由插件提供，新增功能不动内核一行代码。

02 / LAYERING

依赖单向分层

ui → public-api → core → kernel，core 不依赖任何外层实现，依赖规则由 dependency-cruiser 强制。

03 / PORTS

端口可替换

存储、模型网关、文件选择全部抽象为接口：ChatRepository / AiGateway / FileStore，适配器实现可随时更换。

04 / EVENTS

扩展靠事件

插件经 slot 与事件总线接入，内核零改动。GEO 采集 / 流水线 / 分析全部以插件形式挂载。

05 / SECURITY

密钥不进前端

DeepSeek Key 只存后端代理，前端零密钥。安全边界明确，密钥泄漏面收敛到服务端。

Design Goals

设计目标与取舍

四个明确目标，三个清醒取舍——用一点装配复杂度，换解耦与扩展自由。

01 · 可扩展

插件挂载新能力

新能力以插件挂载，内核与既有插件零改动；GEO 三插件即为例证。

02 · 可测试

core 零外部依赖

单元 / 契约 / 集成三层测试，CI 强制，核心逻辑可用替身完整验证。

03 · 可替换

适配器即插即用

存储、模型网关、文件选择均抽象为端口，换实现不动 core。

04 · 安全

零泄漏面

密钥只存在于后端代理，前端代码零密钥、零泄漏面。

取舍 01

启动复杂度

内核加插件装配比单体多一步，换取解耦与扩展自由。

取舍 02

流程隐式化

事件总线解耦调用方，事件契约需文档化，避免隐式依赖失控。

取舍 03

间接层

端口抽象引入少量间接，换来实现可替换与测试替身注入。

Plugin Details

插件内部：采集 · 流水线 · GEO 分析

每个插件都是可独立替换的单元，步骤之间靠事件衔接。

content-fetcher

多源并发采集 + Playwright 兜底

RSS 内置信源（7 个）

hackernews36krsspai info_q_cngithub_trending bbc_topwallstreetcn

WebFetcher 正文抓取

① 前端 POST {url} → /fetch/body
② Playwright headless 渲染，networkidle 后提取 article 正文
③ 返回 title/content → 标准化 ContentItem

健壮性设计

并发抓取使用 Promise.allSettled，单源失败不阻塞整体；结果按 publishedAt 倒序取 limit 条。 每 60 秒内核定时执行 healthCheck，状态经 content.fetch:health 事件上报 UI。

Playwright 只在后端跑：前端不引入，避免 bundle 膨胀与反爬暴露。

content-pipeline

四步流水线

filter过滤
→
dedup去重
→
summarize摘要
→
rank排序

filter：相关性判断，科技 / AI / 互联网 / 金融；不相关 importance 置 0 丢弃。
dedup：两级去重，SimHash 64 位指纹 + 汉明距离 ≤ 3 判重；语义向量 cosine > 0.85（24 小时窗口放宽至 0.80）。
summarize：AI 生成中英摘要、3–5 标签、importance 0–100 评分与分类。
rank：按 importance + heat 排序，产出最终内容流。

监听 content:fetched → pipeline.run（四步按序执行）→ 发出 content:processed 供 UI 渲染。

语义向量与指纹持久化：PostgreSQL + pgvector，content_items 表带 vector(384) 列， HNSW 索引加速相似检索。过滤 / 去重 / 摘要 / 排序全部可单独替换。

Security & Deploy

安全与部署：密钥收敛 + 双平台上线

密钥泄漏面收敛到服务端；前端任何位置均不出现 Key，构建物可公开审计。

01 · 密钥只在后端

环境变量托管

DEEPSEEK_API_KEY 存于 Railway Variables 环境变量，仓库与代码零密钥。

02 · 前端零密钥

构建产物可公开

.env 仅含 VITE_API_BASE_URL（后端公网地址），构建产物不含任何 Key。

03 · CORS 白名单

来源严格限定

ALLOWED_ORIGINS 限定 localhost:5173 与 GitHub Pages 域名，其余来源拒绝。

Status & Roadmap

当前状态

微内核架构落地，版本 v1.2.2，本地与线上均可运行。

已知限制

聊天依赖有效 DeepSeek Key：欠费或空 Key 时 /chat 返回 402。
语义去重依赖 PostgreSQL + pgvector，需要独立数据库实例。
网页正文抓取依赖后端 Playwright 服务，离线时仅 RSS 可用。
模型网关当前默认 DeepSeek，切换其他模型需更换适配器。

下一步

多模型网关：新增适配器切换不同模型供应商。
GEO 定时巡检：定时任务驱动品牌可见度监控。
内容个性化排序：按用户偏好重排内容流。
多模态输入：语音 / 文件终端口扩展接入。
